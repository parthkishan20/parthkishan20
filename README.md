## 🚀 Featured: AI Resume Tailoring Platform

**[github.com/parthkishan20/resume-tailoring-platform](https://github.com/parthkishan20/resume-tailoring-platform)**

A full-stack AI resume workstation that maintains one master resume in YAML and generates job-specific tailored resumes from pasted job descriptions — with ATS keyword scoring, fit critiques, and chat-driven edits applied directly to the source YAML.

- **Real-time LLM streaming** over Server-Sent Events, with LiteLLM for provider-agnostic model access
- **Automated PDF pipeline** (rendercv + Typst), including AI-powered PDF→YAML import with a normalizer layer that repairs LLM output before rendering
- **23 REST/SSE endpoints** across 7 FastAPI route modules, verified by **89 backend unit tests** and **13 Playwright E2E tests** — including a deterministic LLM mock mode for CI-safe testing
- Built with a **spec-first, multi-agent Claude Code workflow** (design docs → 7 implementation plans → parallel agent builds), shipped as a single Docker container serving API + static frontend

*Stack: Next.js 14 · React 18 · TypeScript · Tailwind CSS · FastAPI · SQLite · LiteLLM · Docker · Playwright*
